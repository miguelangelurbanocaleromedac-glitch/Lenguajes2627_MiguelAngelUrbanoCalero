Conceptos básicos de CSS

  • Modelo de caja (Box Model)
  • Propiedad overflow
  • Propiedad box-sizing
  • Propiedad display

1. Modelo de Caja (Box Model)

Explicación teórica: El Box Model define cómo se estructuran y calculan los elementos HTML en la página, componiéndose de cuatro capas: contenido, padding, border y margin.

2. Propiedad overflow

Explicación teórica: La propiedad overflow determina cómo se gestiona el contenido visual cuando este excede las dimensiones de su contenedor (visible, hidden, scroll, auto).

Texto largo que excede los 70px de alto. Gracias a la regla CSS overflow: auto; se activa automáticamente la barra de desplazamiento.

3. Propiedad box-sizing

Explicación teórica: Define cómo se calcula el ancho y alto total. Con border-box, el padding y el border se incluyen en las dimensiones declaradas.

box-sizing: border-box ajusta todo el tamaño sin romper el diseño.

4. Propiedad display

Explicación teórica: Especifica el tipo de caja de renderizado de un elemento en el flujo del documento (block, inline, inline-block, flex, grid, none).

display: block (Fila completa)
display: inline A display: inline B
