01

¿Qué es un lenguaje de marcas?

Un lenguaje de marcas utiliza etiquetas para describir la información de un documento. Las marcas indican qué partes hay y qué significado tienen; después, una aplicación interpreta esas marcas para mostrar o procesar el contenido.

Se utiliza en páginas web, archivos de configuración y en el intercambio de datos entre aplicaciones. Como normalmente se guarda como texto, puede abrirse con distintos editores y no depende de un único sistema operativo.

02

Características principales

TXT

Texto plano

Se puede leer y modificar con un editor de texto.

</>

Marcas integradas

Las etiquetas forman parte del documento, pero normalmente no aparecen como contenido visible.

↔

Intercambio

Ayuda a compartir información entre aplicaciones y plataformas.

✳

Flexibilidad

La estructura puede adaptarse a los datos y necesidades de cada proyecto.

03

Origen y evolución

Los apuntes explican la evolución desde los primeros estándares hasta los lenguajes actuales:

  1. GMLSurge para estandarizar el intercambio de documentos.
  2. SGMLAmplía y formaliza esa idea como estándar.
  3. HTMLTim Berners-Lee lo impulsa para publicar y visualizar documentos en la web.
  4. XMLSe convierte en un estándar flexible para describir datos mediante etiquetas propias.
  5. XHTMLCombina HTML con reglas de escritura más estrictas inspiradas en XML.

05

Usos habituales

  • Compartir información entre plataformas diferentes.
  • Guardar datos estructurados que después se pueden consultar o filtrar.
  • Convertir información de un formato a otro.
  • Separar los datos de la forma en la que se van a mostrar.

07

XML: estructura y características

XML (eXtensible Markup Language) permite crear etiquetas propias para describir datos. No sustituye a HTML: XML se centra en estructurar información, mientras que HTML se utiliza para construir documentos que se muestran en el navegador.

Su estructura tiene forma de árbol: existe un único nodo raíz y, dentro de él, se organizan los elementos hijos. El documento se puede dividir en un prólogo, con información como la versión y la codificación, y un cuerpo, con los datos.

Ejemplo sencillo de documento XML.
<?xml version="1.0" encoding="UTF-8"?>
<biblioteca ciudad="Madrid">
  <libro>
    <titulo>Aprender HTML</titulo>
    <autor>Ana Ruiz</autor>
    <paginas>180</paginas>
  </libro>
</biblioteca>
08

Cómo conseguir un XML bien formado

  • Debe existir un único elemento raíz que contenga al resto.
  • Cada etiqueta abierta debe cerrarse correctamente.
  • Los elementos deben estar anidados en el orden correcto.
  • Los valores de los atributos deben escribirse entre comillas.
  • Los nombres distinguen mayúsculas y minúsculas: <coche> y <Coche> no son iguales.
  • Los nombres de etiqueta deben respetar las reglas de XML y no comenzar por un número.
  • Los comentarios se escriben con <!-- ... -->.

Un documento bien formado respeta la sintaxis de XML. Un validador o un editor con comprobación XML ayuda a detectar errores.

09

Espacios de nombres

Los espacios de nombres evitan confusiones cuando se combinan documentos XML que utilizan la misma etiqueta para conceptos diferentes. Se declara un identificador con xmlns y se usan prefijos delante de las etiquetas.

Dos etiquetas con el mismo nombre, pero distinto espacio de nombres.
<datos xmlns:rio="https://ejemplo.es/rios"
       xmlns:tv="https://ejemplo.es/television">
  <rio:canal>Canal de agua</rio:canal>
  <tv:canal>Canal de televisión</tv:canal>
</datos>

Idea clave del tema

Un lenguaje de marcas estructura la información. XML permite definir etiquetas propias y organizar los datos en un árbol con reglas sintácticas claras.

Reto práctico inspirado en los apuntes

Ahora toca ponerlo en práctica

Clasificar varios lenguajes de marcas y crear un XML que reúna información de libros de diferentes bibliotecas. Si aparecen etiquetas con el mismo nombre y significado distinto, se pueden separar mediante espacios de nombres.
