01

Estructura de una tabla

La etiqueta <table> crea una tabla. Una tabla está formada por filas y celdas y resulta útil para mostrar datos que guardan relación entre sí.

EtiquetaFunción
<caption>Título de la tabla.
<thead>Agrupa la cabecera.
<tbody>Agrupa el contenido principal.
<tfoot>Agrupa el pie.
<tr>Crea una fila.
<th> / <td>Celda de cabecera / celda de datos.
Ejemplo de tabla organizada por secciones.
<table>
  <caption>Horario de cursos</caption>
  <thead>
    <tr><th>Curso</th><th>Horario</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>16:00 - 20:00</td></tr>
    <tr><td>CSS</td><td>09:00 - 12:00</td></tr>
  </tbody>
  <tfoot>
    <tr><th>Total</th><td>35 horas</td></tr>
  </tfoot>
</table>
02

Agrupar columnas y combinar celdas

<colgroup> y <col> permiten agrupar o identificar columnas para poder aplicarles estilos. Para unir celdas se utilizan dos atributos:

  • colspan: une varias columnas en horizontal.
  • rowspan: une varias filas en vertical.
Ejemplo de colspan y rowspan.
<tr>
  <th colspan="2">Datos del curso</th>
</tr>
<tr>
  <th rowspan="2">Mañana</th>
  <td>HTML</td>
</tr>
<tr><td>CSS</td></tr>
03

¿Para qué sirven los formularios?

Los formularios agrupan controles para recoger datos del usuario y enviarlos a un servidor. La etiqueta principal es <form>. Sus atributos más importantes son action, que indica dónde se envían los datos, y method, que define cómo se envían.

04

Métodos GET y POST

GET

Los datos viajan en la URL

Los valores aparecen en la dirección de la página. Es adecuado para búsquedas o filtros no sensibles.

POST

Los datos van en el cuerpo de la petición

No aparecen en la URL. Suele utilizarse al enviar formularios con datos que no deben mostrarse en la dirección.

Usar POST no cifra por sí solo la información. Para proteger los datos durante el envío se necesita HTTPS y medidas adecuadas en el servidor.

Ejemplo de formulario que envía datos mediante POST.
<form action="procesar.php" method="post">
  <!-- Controles del formulario -->
  <button type="submit">Enviar</button>
</form>
05

Atributos habituales de los controles

typenamevaluerequiredsizeminlengthmaxlengthautofocusdisabledreadonlytabindex

type determina el tipo de control; name identifica el dato; value establece un valor; required marca un campo como obligatorio; minlength y maxlength limitan la longitud. disabled desactiva el control, mientras que readonly permite verlo y enfocarlo, pero no modificarlo.

06

Tipos de controles

Botones

button ejecuta una acción; submit envía el formulario; reset restaura los valores iniciales.

Texto

text introduce texto; password oculta lo escrito; textarea permite varias líneas.

Selección múltiple

checkbox permite marcar varias opciones.

Selección única

radio permite elegir una opción dentro de un grupo con el mismo nombre.

Lista desplegable

select agrupa opciones option.

Agrupación

fieldset agrupa controles y legend pone un título al grupo.

Ejemplo sencillo de formulario.
<form action="#" method="get">
  <fieldset>
    <legend>Datos de contacto</legend>
    <label for="nombre">Nombre</label>
    <input id="nombre" name="nombre" type="text" required>

    <label for="mensaje">Mensaje</label>
    <textarea id="mensaje" name="mensaje" rows="4"></textarea>

    <button type="submit">Enviar</button>
    <button type="reset">Borrar</button>
  </fieldset>
</form>

Idea clave del tema

Las tablas organizan datos en filas y columnas. Los formularios recogen información y necesitan controles bien identificados, etiquetas y un método de envío adecuado.
