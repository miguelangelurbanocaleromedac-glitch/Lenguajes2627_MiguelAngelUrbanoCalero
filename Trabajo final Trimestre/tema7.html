01

¿Qué es CSS?

CSS significa Cascading Style Sheets (hojas de estilo en cascada). Se utiliza para controlar la presentación visual de un documento HTML: colores, tamaños, fuentes, espacios y distribución.

HTML define el contenido y su estructura; CSS define cómo se muestra. Separarlos permite cambiar el diseño sin tener que reescribir el contenido.

02

Tres formas de incluir CSS

En línea

Se escribe el estilo en el atributo style de una etiqueta. Es rápido, pero difícil de mantener cuando se repite.

Interno

Se coloca una regla dentro de <style> en la cabecera HTML.

Externo

Se guardan las reglas en un archivo .css y se enlaza con <link>. Es la opción más cómoda para un sitio con varias páginas.

Ejemplo de hoja de estilos externa.
<!-- En el head del HTML -->
<link rel="stylesheet" href="css/style.css">

/* En el archivo style.css */
p {
  color: #243b53;
  text-align: left;
}
03

Sintaxis de una regla CSS

Una regla CSS tiene un selector y un bloque de declaraciones. Cada declaración contiene una propiedad y un valor.

Selector: h1 · Propiedades: color, font-size y text-align · Valores: los indicados.
h1 {
  color: #0b7a75;
  font-size: 2rem;
  text-align: center;
}

Las declaraciones se separan con punto y coma. Los comentarios empiezan con /* y terminan con */.

05

Herencia y conflictos entre estilos

Algunas propiedades se heredan desde un elemento padre a sus elementos hijos. Por ejemplo, si un contenedor tiene un color de texto, sus párrafos pueden recibirlo automáticamente.

Si una regla más concreta define otro valor para un hijo, ese estilo puede prevalecer. Cuando dos reglas tienen la misma especificidad, normalmente se aplica la que aparece después. El inspector del navegador ayuda a ver qué reglas están actuando.

06

Unidades de medida

TipoUnidadesUso
Absolutaspx, cm, mm, in, pt, pcExpresan una medida concreta.
Relativasem, rem, %, vw, vhDependen de la fuente, el elemento padre o el tamaño de la ventana.

em se relaciona con el tamaño de fuente del elemento padre; rem con el tamaño de fuente raíz; % con una referencia del elemento contenedor; vw y vh con el ancho y alto de la ventana.

07

Formas de representar colores

En CSS se puede indicar un color mediante su nombre, el modelo RGB o un valor hexadecimal. En RGB cada componente rojo, verde y azul puede tomar un valor de 0 a 255.

Tres formas diferentes de indicar colores.
h1 { color: red; }
p  { color: rgb(20, 90, 130); }
.card { background-color: #e8f3f2; }

Es recomendable mantener una paleta coherente y comprobar que existe suficiente contraste entre el texto y el fondo para facilitar la lectura.

Idea clave del tema

CSS controla la presentación del HTML. Las reglas se aplican mediante selectores y propiedades, y la cascada decide qué estilo prevalece.
