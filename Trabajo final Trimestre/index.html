ORDEN DE APRENDIZAJE

Un recorrido paso a paso

Los contenidos se han agrupado siguiendo la progresión de los apuntes: primero los fundamentos, después HTML y, por último, CSS.

01 · Temas 1–2

Entender el lenguaje

Aprende qué son las marcas, para qué sirve XML y cómo el navegador interpreta HTML.

02 · Temas 3–6

Construir el contenido

Organiza páginas, utiliza enlaces y listas, crea tablas y formularios y aprovecha HTML5.

03 · Temas 7–9

Diseñar la experiencia

Aplica CSS, controla propiedades y cajas, posiciona elementos y añade efectos visuales.

CALIDAD DEL PROYECTO

Diseñado para cumplir la evaluación

La organización y la presentación están pensadas para responder a los criterios de valoración del trabajo.

✓
HTML semántico y ordenado

Se utilizan cabecera, navegación, contenido principal, secciones y pie de página.

✓
CSS común en todo el sitio

Una sola hoja de estilos mantiene colores, tipografía, espacios y componentes homogéneos.

✓
Navegación clara

Menú principal, índice de cada página y enlaces entre temas anterior y siguiente.

✓
Diseño adaptable

La distribución se reorganiza para móviles, tabletas y pantallas grandes.

✓
Contenido organizado

Explicaciones, tablas, ejemplos de código, objetivos y retos prácticos por unidad.

✓
Preparado para Git y GitHub

Se incluye una guía de comandos básicos para guardar y publicar las versiones del proyecto.
