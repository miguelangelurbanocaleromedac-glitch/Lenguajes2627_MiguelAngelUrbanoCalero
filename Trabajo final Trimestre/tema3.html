01

Las tres partes del documento

Un documento HTML5 se compone de una declaración de tipo de documento, una cabecera y un cuerpo. La etiqueta <html> contiene todo el documento; <head> guarda información sobre la página y <body> contiene lo que se muestra al usuario.

Estructura mínima de HTML5.
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola, mundo</h1>
  <p>Mi primera página web.</p>
</body>
</html>
02

Tipo de documento (DOCTYPE y DTD)

La declaración <!DOCTYPE html> indica al navegador que se está utilizando HTML5. En HTML 4.01 existían declaraciones DTD como Strict, Transitional y Frameset, cada una con reglas diferentes. En HTML5 la declaración se simplificó.

Omitir el DOCTYPE puede hacer que el navegador entre en un modo de compatibilidad con documentos antiguos y produzca diferencias de visualización.

03

La cabecera: metadatos y recursos

Dentro de <head> se incluyen datos que describen el documento y referencias a recursos:

  • <title>: texto de la pestaña del navegador.
  • <meta>: metadatos, como descripción, autor o codificación.
  • <link>: enlaza recursos externos, por ejemplo una hoja CSS.
  • <style>: permite escribir CSS dentro del propio HTML.
  • <script>: incorpora o enlaza scripts.

Para mantener el código organizado, es recomendable guardar el CSS y los scripts en archivos externos cuando el proyecto crece.

Ejemplo de cabecera.
<head>
  <meta charset="UTF-8">
  <meta name="description" content="Guía de HTML básico">
  <meta name="author" content="WebLab">
  <title>Guía de HTML</title>
  <link rel="stylesheet" href="css/style.css">
</head>
04

Codificación de caracteres (charset)

La codificación relaciona los caracteres que escribimos con los datos que el ordenador almacena. Los apuntes presentan ASCII, ISO-8859-1, ANSI y UTF-8. UTF-8 es la opción habitual en HTML5 porque admite una gran variedad de caracteres y evita problemas con acentos, eñes y símbolos.

La codificación se declara con <meta charset="UTF-8">. También existen entidades HTML para escribir caracteres reservados o símbolos especiales, por ejemplo &lt; representa el signo menor que.

05

Contenido del body: párrafos y separadores

El cuerpo contiene el contenido principal de la página. Para crear párrafos se utiliza <p>. La etiqueta <hr> dibuja una separación temática mediante una línea horizontal.

Ejemplo de párrafos y separador.
<p>Primer párrafo de información.</p>
<hr>
<p>Segundo párrafo, después del separador.</p>
06

Divisiones y divisiones anidadas

<div> agrupa otros elementos para tratarlos como un bloque. Se pueden introducir unas divisiones dentro de otras para organizar mejor el contenido y aplicar estilos CSS a cada grupo.

No conviene utilizar divisiones sin necesidad: son útiles cuando agrupan varios elementos que deben tratarse en conjunto.

Ejemplo de divisiones anidadas.
<div class="tarjeta">
  <h2>Datos personales</h2>
  <div class="datos">
    <p>Nombre: Alex</p>
    <p>Estudios: DAW</p>
  </div>
</div>
07

Citas largas y texto preformateado

<blockquote> sirve para incluir una cita extensa que puede contener varios párrafos u otros elementos. <pre> muestra el texto respetando los espacios, tabulaciones y saltos de línea que se escribieron en el código.

Ejemplo de blockquote y pre.
<blockquote>
  <p>La práctica ayuda a entender la estructura de una página.</p>
</blockquote>

<pre>
Nombre:  Alex
Ciclo:   DAW
Curso:   Primero
</pre>
08

Títulos y jerarquía de secciones

Los encabezados se escriben con las etiquetas <h1> a <h6>. h1 representa el título de mayor nivel y h6 el de menor nivel. Deben organizarse de forma lógica, sin saltar niveles por motivos puramente visuales.

Una estructura habitual es usar h1 para el título de la página, h2 para los apartados y h3 para subapartados.

Idea clave del tema

La estructura separa los metadatos del contenido visible. Un documento ordenado con DOCTYPE, head y body es más fácil de interpretar y mantener.

Reto práctico inspirado en los apuntes

Ahora toca ponerlo en práctica

Preparar una ficha HTML con nombre, estudios, correo y teléfono. Añadir comentarios, agrupar los datos con div y utilizar pre para conservar la alineación de un bloque de texto.
