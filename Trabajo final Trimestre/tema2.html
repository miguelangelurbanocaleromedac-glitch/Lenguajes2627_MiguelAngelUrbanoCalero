01

¿Qué es HTML?

HTML significa HyperText Markup Language. Es un lenguaje de marcas que permite crear documentos web. El navegador interpreta su estructura y muestra el contenido al usuario.

En el modelo cliente-servidor, el navegador (cliente) solicita una página a un servidor mediante una dirección URL. El servidor devuelve el documento HTML y el navegador lo interpreta.

02

Etiquetas y sintaxis

Las etiquetas se escriben entre los símbolos < y >. Muchas tienen una etiqueta de apertura y otra de cierre; la de cierre incluye una barra.

Ejemplo de etiquetas HTML. Algunas, como img y hr, no necesitan una etiqueta de cierre.
<p>Este es un párrafo.</p>
<p>Este texto tiene una palabra <strong>importante</strong>.</p>
<hr>
<img src="foto.jpg" alt="Descripción de la imagen">
03

Atributos y comentarios

Los atributos añaden información a una etiqueta y se colocan en la etiqueta de apertura. Normalmente se escriben como nombre, signo igual y valor entre comillas.

Ejemplo de atributos src, alt, width, height, href y title.
<img src="paisaje.jpg" alt="Montañas al amanecer"
     width="640" height="360">
<a href="https://ejemplo.es" title="Visitar la página">Visitar</a>
<!-- Este comentario no aparece en el navegador -->

Atributos frecuentes

href indica el destino de un enlace; id identifica un elemento; style aplica estilos en línea; title aporta información adicional; disabled desactiva un control.

Comentarios

Se escriben entre <!-- y -->. Sirven para documentar el código y no se muestran en la página.

04

¿Qué es un elemento HTML?

Un elemento es el conjunto formado por la etiqueta de apertura, sus atributos (si los tiene), el contenido y la etiqueta de cierre. Por eso, una etiqueta y un elemento no son exactamente lo mismo.

EN LÍNEA

Elemento en línea

Ocupa el espacio que necesita su contenido y puede aparecer dentro de una línea de texto. Ejemplo: <a> o <span>.

EN BLOQUE

Elemento de bloque

Comienza en una línea nueva y normalmente ocupa todo el ancho disponible. Ejemplo: <p> o <div>.

05

Ejemplo: atributos de la imagen

La etiqueta <img> permite incluir una imagen. Los apuntes destacan cuatro atributos:

  • src: ruta del archivo de imagen.
  • alt: texto alternativo si no se puede mostrar la imagen.
  • width: ancho.
  • height: alto.

Es importante escribir un texto alternativo útil, porque ayuda a comprender el contenido cuando la imagen no está disponible.

06

Versiones de HTML

VersiónCaracterísticas destacadas en los apuntes
HTML 2.0Versión sencilla; todavía no incluía tablas.
HTML 3.2Incorporó tablas y opciones de diseño más avanzadas.
HTML 4.01Mejoró los formularios y permitió integrar scripts.
HTML5Añadió etiquetas semánticas y soporte directo para audio y vídeo.

El navegador interpreta el HTML. Como puede haber diferencias de compatibilidad, conviene comprobar cómo se visualiza la página en distintos navegadores.

07

Diferencias entre HTML y XHTML

XHTML es una formulación de HTML basada en XML. Por eso exige una sintaxis más estricta. En XHTML se deben cerrar los elementos, respetar el anidamiento, escribir los nombres en minúsculas y poner entre comillas los valores de los atributos.

HTML moderno es más flexible en algunos aspectos, pero mantener un código bien ordenado y cerrar correctamente las etiquetas sigue siendo una buena práctica.

08

Herramientas de diseño y validación

Se puede escribir HTML en editores como Visual Studio Code o Notepad++. También existen editores online y herramientas de validación que comprueban errores de sintaxis y ayudan a detectar etiquetas o atributos mal utilizados.

La validación no sustituye a probar la página en el navegador, pero es una forma útil de revisar el código.

Idea clave del tema

HTML aporta la estructura del documento. Las etiquetas identifican elementos, los atributos añaden información y el navegador interpreta el conjunto.

Reto práctico inspirado en los apuntes

Ahora toca ponerlo en práctica

Crear una página con varias imágenes y utilizar correctamente src, alt, width y height. Después, validar un documento con sintaxis XHTML para detectar errores de cierre, anidamiento o atributos.
