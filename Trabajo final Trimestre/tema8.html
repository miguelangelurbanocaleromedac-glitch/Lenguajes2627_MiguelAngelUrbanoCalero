01

Propiedades del texto

Las propiedades de texto permiten controlar la alineación, el color, el fondo, el subrayado, el espaciado y la transformación de mayúsculas o minúsculas.

text-aligncolorbackground-colortext-decorationletter-spacingword-spacingtext-transformline-height
Ejemplo de propiedades del texto.
p {
  text-align: justify;
  color: #243b53;
  line-height: 1.6;
  letter-spacing: 0.2px;
}
02

Propiedades de las fuentes

Las propiedades de fuentes controlan la familia tipográfica, el tamaño, el estilo y el grosor de los caracteres.

PropiedadFunción
font-familyFamilia de la fuente.
font-sizeTamaño del texto.
font-styleEstilo normal o cursiva.
font-weightGrosor, por ejemplo normal o bold.

Se pueden usar fuentes seguras instaladas en el sistema o incorporar otras fuentes mediante servicios como Google Fonts o la regla @font-face.

03

Propiedades de las listas

Con CSS se puede cambiar el tipo de viñeta, usar una imagen como marcador y elegir la posición de la viñeta.

  • list-style-type: tipo de viñeta (disc, circle, square o none).
  • list-style-image: imagen que se usa como viñeta.
  • list-style-position: coloca la viñeta dentro o fuera del bloque de texto.
04

Pseudoclases y pseudoelementos

Las pseudoclases seleccionan un elemento según su posición o estado. Se escriben con dos puntos. Los pseudoelementos permiten dar estilo a una parte concreta del contenido y se escriben con dos puntos dobles.

SelectorSignificado
:first-childPrimer hijo.
:last-childÚltimo hijo.
:nth-child(n)Hijo según su posición; admite odd y even.
:hoverEl cursor pasa por encima.
:focusEl elemento recibe el foco.
:activeEl elemento está siendo activado.
:link / :visitedEnlace no visitado / visitado.
::first-letterPrimera letra.
::first-linePrimera línea.
::before / ::afterContenido antes o después.
Ejemplos de pseudoclases y pseudoelementos.
li:first-child { color: #087f74; }
li:nth-child(even) { background: #eef5f4; }
a:hover { text-decoration: underline; }
p::first-letter { font-size: 1.5em; }
.note::before { content: "Nota: "; }
05

Propiedades de las tablas

Además de los estilos comunes, las tablas disponen de propiedades para controlar la distribución y los bordes.

  • caption-side: coloca el título arriba o abajo.
  • table-layout: define cómo se calcula la distribución de columnas.
  • border-collapse: une o separa los bordes.
  • border-spacing: establece la separación entre celdas.
  • empty-cells: controla la visualización de celdas vacías.
  • vertical-align: alinea verticalmente el contenido.
06

El modelo de cajas

CSS considera cada elemento HTML como una caja rectangular. El modelo de cajas explica el espacio que ocupa cada elemento y la separación que mantiene con los demás.

margin · margen
border · borde
padding · relleno

contenido
Content El texto, imagen o contenido.Padding Espacio entre contenido y borde.Border Línea que rodea el contenido y el relleno.Margin Espacio exterior entre cajas.
07

Tamaño y comportamiento de las cajas

Las dimensiones se controlan con width, height, min-width, max-width, min-height y max-height. Con auto, el navegador calcula el tamaño según el contenido y el espacio disponible.

Otras propiedades importantes son:

  • padding, margin y border: controlan el espacio interior, exterior y el borde.
  • background-image, background-position, background-size, background-repeat y background-attachment: configuran el fondo.
  • box-sizing: define cómo se calcula el tamaño total de la caja.
  • display: modifica el comportamiento de la caja, por ejemplo block, inline o none.
  • visibility: muestra u oculta el elemento sin eliminar su espacio.
  • overflow: define qué ocurre cuando el contenido no cabe (visible, hidden, scroll o auto).
Ejemplo de tamaño y modelo de cajas.
.caja {
  width: 300px;
  padding: 20px;
  border: 2px solid #0b7a75;
  margin: 16px;
  box-sizing: border-box;
}

Idea clave del tema

Las propiedades CSS controlan los detalles visuales. El modelo de cajas ayuda a entender el tamaño real de cada elemento y el espacio que lo rodea.
