01

Disposición y flujo normal

Por defecto, los elementos en línea aparecen uno junto a otro mientras que los elementos de bloque comienzan en una línea nueva. CSS permite cambiar esa disposición para colocar imágenes, párrafos, menús y otras cajas donde sea necesario.

02

La propiedad position

ValorComportamiento
staticPosición normal del documento. Es el valor por defecto.
relativePermite desplazar la caja respecto a su posición original.
absolutePosiciona la caja respecto a su contenedor de referencia.
fixedLa caja permanece en una posición de la ventana aunque se haga scroll.

Para indicar el desplazamiento se utilizan top, bottom, left y right. z-index controla qué elemento queda por delante cuando varias cajas se superponen.

Ejemplo de elemento fijo en la ventana.
.aviso {
  position: fixed;
  top: 16px;
  right: 16px;
  z-index: 10;
}
03

Posicionamiento flotante: float y clear

float permite que una caja se coloque a la izquierda o a la derecha y que el contenido fluya a su alrededor. clear evita que un elemento quede junto a elementos flotantes en el lado indicado.

Ejemplo de float y clear.
.foto { float: left; margin-right: 16px; }
.fin-flotantes { clear: both; }

En los apuntes se utiliza este mecanismo para crear un menú horizontal y para alinear imágenes a los lados de artículos. También se observa que, al reducir el ancho de la ventana, las cajas pueden saltar a otra línea si ya no caben.

04

Novedades y propiedades CSS3

CSS3 amplía las posibilidades de presentación con nuevas propiedades y efectos. En los apuntes se destacan los bordes redondeados, sombras, opacidad, gradientes, fuentes web, multicolumnas y transformaciones.

05

Bordes, sombras, opacidad y gradientes

◒

Bordes redondeados

border-radius redondea las esquinas de una caja.

▧

Sombras

box-shadow crea sombras de caja y text-shadow de texto.

◐

Opacidad

opacity controla la transparencia entre 0 y 1.

▤

Gradientes

linear-gradient() y radial-gradient() mezclan colores.

Ejemplo de acabados CSS3.
.tarjeta {
  border-radius: 18px;
  box-shadow: 0 12px 30px rgba(20, 40, 60, .12);
  background: linear-gradient(120deg, #e9f5f2, #ffffff);
}
06

Fuentes web y multicolumnas

La regla @font-face permite declarar una fuente externa con un nombre que después se utilizará en font-family. También se puede enlazar un servicio de fuentes web.

Para distribuir texto en varias columnas se utilizan column-count (número de columnas), column-gap (separación) y column-rule (línea divisoria).

Ejemplo de multicolumnas.
.texto-columnas {
  column-count: 2;
  column-gap: 28px;
  column-rule: 1px solid #d8e3e1;
}
07

Transformaciones, transiciones y animaciones

transform permite transformar un elemento. Los apuntes presentan estas funciones principales:

  • translate(x, y): desplaza el elemento.
  • rotate(x): lo gira un número de grados.
  • scale(x, y): cambia su escala.

Las transiciones suavizan el cambio entre estados, por ejemplo al pasar el cursor por encima de un botón. Las animaciones permiten definir secuencias de cambios mediante reglas CSS.

Ejemplo de transición y transformación.
.boton {
  transition: transform .2s ease, background-color .2s ease;
}
.boton:hover {
  transform: translateY(-3px) scale(1.02);
}

Idea clave del tema

CSS permite controlar dónde aparece cada elemento y mejorar su aspecto con bordes, sombras, gradientes, fuentes, transformaciones y transiciones.
