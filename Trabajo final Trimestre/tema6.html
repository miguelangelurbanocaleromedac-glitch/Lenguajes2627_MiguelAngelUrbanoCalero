01

Web semántica y mejoras de HTML5

La web semántica pretende que las partes del documento tengan un significado reconocible. HTML5 amplía las etiquetas disponibles y facilita crear páginas con una estructura más clara.

Los apuntes destacan mejoras en semántica, multimedia, gráficos 2D/3D, almacenamiento local, rendimiento, geolocalización y funciones como arrastrar y soltar. También refuerza la separación entre contenido HTML y presentación CSS.

02

Etiquetas semánticas principales

<header> · Cabecera
<nav> · Navegación
<main> · Contenido principal
<section>Sección temática
<article> · Contenido autónomo
<aside> · Contenido secundario
<footer> · Pie de página

header presenta una cabecera; nav agrupa enlaces de navegación; main contiene el contenido principal y se utiliza una sola vez; section agrupa contenido de una misma temática; article representa una pieza autónoma; aside contiene información complementaria; footer reúne información del pie.

03

Nuevos controles de formulario

HTML5 incorpora nuevos valores para el atributo type de input. El navegador puede validar algunos datos y ofrecer controles adaptados.

TipoUtilidad
emailComprueba el formato de una dirección de correo.
urlSolicita una dirección web.
date / timePermite seleccionar fecha u hora.
numberPermite introducir un valor numérico.
rangeOfrece un control deslizante.
colorAbre un selector de color.

También se incluyen atributos como placeholder para mostrar una indicación, min y max para establecer límites y pattern para validar un formato.

Ejemplo de controles HTML5.
<label for="correo">Correo</label>
<input id="correo" name="correo" type="email" required>

<label for="fecha">Fecha</label>
<input id="fecha" name="fecha" type="date">

<label for="nivel">Nivel</label>
<input id="nivel" name="nivel" type="range" min="1" max="10">
04

Elementos de progreso y medida

<progress> representa el avance de una tarea, como una descarga o un proceso. <meter> representa una medida dentro de un rango conocido.

Ejemplo de progress y meter.
<label for="avance">Progreso del proyecto</label>
<progress id="avance" value="35" max="100">35%</progress>

<label for="ocupacion">Ocupación</label>
<meter id="ocupacion" min="0" max="100" value="72">72%</meter>
05

Audio y vídeo

HTML5 permite insertar sonido y vídeo sin depender obligatoriamente de complementos externos. Se utilizan las etiquetas <audio> y <video>, normalmente acompañadas de <source> para indicar los archivos disponibles.

  • controls: muestra los controles de reproducción.
  • loop: repite el recurso al terminar.
  • preload: controla la precarga.
  • En vídeo también pueden utilizarse width, height, muted y poster.
Ejemplo de audio y vídeo.
<audio controls>
  <source src="audio/podcast.mp3" type="audio/mpeg">
  Tu navegador no puede reproducir este audio.
</audio>

<video controls width="640" poster="img/portada.jpg">
  <source src="video/explicacion.mp4" type="video/mp4">
  Tu navegador no puede reproducir este vídeo.
</video>
06

Imágenes con descripción

<figure> agrupa una imagen u otro contenido independiente y <figcaption> añade su descripción o pie.

Ejemplo de figure y figcaption.
<figure>
  <img src="img/aula.jpg" alt="Aula de informática">
  <figcaption>Un aula preparada para practicar HTML.</figcaption>
</figure>
07

Elementos interactivos: details y summary

<details> permite mostrar u ocultar información. Dentro se coloca <summary>, que contiene el título visible del desplegable. El atributo open hace que aparezca abierto al cargar la página.

Ejemplo de preguntas frecuentes con details.
<details>
  <summary>¿Qué significa HTML?</summary>
  <p>HyperText Markup Language.</p>
</details>

<details open>
  <summary>¿Qué es CSS?</summary>
  <p>Un lenguaje para definir la presentación visual.</p>
</details>

Idea clave del tema

HTML5 aporta significado a la estructura, amplía los formularios e integra recursos multimedia y elementos interactivos directamente en el documento.

Reto práctico inspirado en los apuntes
