01

Etiquetas para dar significado al texto

Las etiquetas de texto permiten destacar partes de un contenido, añadir significado o modificar cómo se presenta. Es importante elegir la etiqueta según el significado, no solo por su apariencia.

<br><span><em><strong><sub><sup><b><s><i><small><mark>
Ejemplos de etiquetas de texto.
<p>HTML es <strong>importante</strong> para la web.</p>
<p>Este texto tiene <em>énfasis</em> y una palabra <mark>resaltada</mark>.</p>
<p>Agua: H<sub>2</sub>O. Potencia: 2<sup>3</sup>.</p>
<p><small>Nota secundaria.</small></p>
<p>Línea uno<br>Línea dos</p>

<span> se utiliza como contenedor en línea cuando no hay una etiqueta semántica más adecuada. En los apuntes también se citan <cite>, <q>, <dfn>, <abbr>, <time> y <kbd>.

02

Enlaces con la etiqueta a

Los enlaces conectan documentos y permiten navegar entre distintas partes de una web o hacia páginas externas. Se crean con <a> y el atributo href indica el destino.

Ejemplos de enlaces externos, internos y a un archivo.
<a href="https://www.ejemplo.es">Visitar la web</a>
<a href="#contacto">Ir al contacto</a>
<a href="documento.pdf" target="_blank">Abrir documento</a>

<section id="contacto">
  <h2>Contacto</h2>
</section>

El atributo target indica dónde se abre el destino: _self utiliza la pestaña actual y _blank abre una nueva. Los apuntes también describen _parent y _top, relacionados con marcos.

03

Listas ordenadas, no ordenadas y de definición

HTML ofrece tres tipos principales de listas:

<ol>

Lista ordenada. Los elementos aparecen numerados o siguiendo un tipo de orden.

<ul>

Lista no ordenada. Los elementos se muestran con viñetas.

<dl>

Lista de definiciones, con términos (dt) y sus descripciones (dd).

Los elementos de las listas ordenadas y no ordenadas se escriben con <li>. También se pueden anidar listas para crear subapartados.

Ejemplo de lista anidada.
<ul>
  <li>HTML
    <ul>
      <li>Etiquetas</li>
      <li>Atributos</li>
    </ul>
  </li>
  <li>CSS</li>
</ul>
04

Contenido incrustado: imágenes

La etiqueta <img> incorpora una imagen externa al documento. Los atributos principales son:

  • src: ubicación del archivo.
  • alt: descripción alternativa.
  • title: información adicional que puede mostrarse al pasar el cursor.
  • width y height: dimensiones de la imagen.
Ejemplo de imagen con texto alternativo.
<img src="img/paisaje.jpg"
     alt="Montañas y un lago"
     width="640" height="360">
05

Documentos HTML incrustados

<iframe> permite mostrar otro documento HTML dentro de la página actual. Se suele usar para insertar mapas, recursos externos o contenido compartido desde otros servicios.

Ejemplo básico de iframe.
<iframe src="https://ejemplo.es/recurso"
        title="Recurso de ejemplo"
        width="600" height="350">
</iframe>

Es recomendable incluir un título descriptivo y comprobar que el servicio externo permite ser insertado en otra página.

Idea clave del tema

Las etiquetas de texto aportan significado, los enlaces conectan contenidos, las listas organizan la información y las imágenes o iframes añaden recursos externos.
